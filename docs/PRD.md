# PRD — Signal Desk 盯盘预警与策略台

- 版本: 0.1.0 (draft)
- 日期: 2026-08-28
- 状态: 设计中，未开工

## 1. 一句话定位

面向**中国期货**与**加密货币**的多级别技术形态盯盘预警系统；同一套信号引擎向下延伸到策略回测与自动交易。

## 2. 目标用户与场景

单人交易者（本人）。核心场景：

1. 盯盘替代 —— 我不再需要人肉切周期看图，符合我定义的形态时手机收到推送。
2. 形态验证 —— 一条形态到底赚不赚钱，用历史数据跑一遍给出统计，而不是凭感觉。
3. 逐步自动化 —— 验证过的形态升级成策略，先模拟盘，再小仓实盘。

## 3. 范围

### 3.1 In scope

| 能力 | 说明 |
|---|---|
| 多市场行情接入 | 中国期货（数据商行情）+ 加密（交易所 WS/REST），双线并行 |
| 多级别 K 线合成 | 按交易日历合成，多周期同源，无未来函数 |
| 形态定义 | ① 指标类表达式 ② K线/价格结构原语 ③ 自定义 Python 插件 |
| 多级别交叉规则 | trend / setup / trigger 三段式 + 状态机 + TTL/冷却/去重 |
| 预警投递 | Telegram / Bark / 飞书 webhook |
| Web 界面 | 信号流、K线回看（信号标注）、规则管理、运行状态 |
| 信号质量统计 | 触发次数、胜率、期望收益、假信号率、分品种/分时段分布 |
| 回测 | 与实时共用同一引擎，历史回放 |
| 自动交易 | 期货走 CTP，加密走交易所 API；纸上撮合先行 |

### 3.2 Out of scope（本期不做）

- 缠论 / 波浪 等递归结构理论（架构预留插件位，不内建）
- 股票、期权、外汇
- 多用户 / 权限 / SaaS 化
- 高频（本系统面向分钟级及以上，不追求微秒延迟）
- 机器学习选股/择时

## 4. 关键需求

### FR-1 行情与合约
- FR-1.1 期货行情走 Quote API（`<自有行情服务，地址配在 .env 的 QUOTE_API_BASE>`，HTTP 轮询，1m~月线，无推送无 tick）；交易通道独立走 CTP。见 ADR-0002。
- FR-1.2 统一标的标识与三方代码映射（内部 symbol ↔ 数据商代码 ↔ CTP 代码 ↔ 交易所代码）。
- FR-1.3 期货支持交易日历（日盘/夜盘/节假日/集合竞价），K 线按 session 切分。
- FR-1.4 主力换月：预警默认作用于**真实合约**；连续合约仅用于长周期回测与画图，且必须标注拼接方式。
- FR-1.5 断线自动重连；期货用重叠窗口轮询校验缺口，加密断线后 REST 回补。

### FR-2 指标与形态
- FR-2.1 指标增量计算，区分「已收盘 bar」与「进行中 bar」。
- FR-2.2 内建指标：MA/EMA/MACD/RSI/BOLL/ATR/KDJ/成交量均线。
- FR-2.3 内建结构原语：swing_high/low、breakout、range(箱体)、gap、engulfing、pin_bar、consolidation。
- FR-2.4 表达式引擎：白名单 AST 求值，禁用 eval/exec/import。
- FR-2.5 Python 插件：装饰器注册，只能通过受限上下文访问数据（结构上无法取到未来数据）。

### FR-3 多级别规则
- FR-3.1 一条规则可绑定 1~3 个周期角色：trend(方向过滤) / setup(条件成形) / trigger(触发)。
- FR-3.2 条件模式：`state`(持续状态) / `window`(最近 N 根内出现过) / `event`(边沿触发)。
- FR-3.3 每个 (标的, 规则) 独立状态机：IDLE → TREND_OK → SETUP_ARMED(TTL) → FIRED → COOLDOWN。
- FR-3.4 大级别一律取**最近已收盘** bar，禁止使用进行中 bar 参与 trend 判定。
- FR-3.5 触发确认：默认 `confirm_on_close`（小级别收盘才报），可选盘中预报（标记为 tentative）。
- FR-3.6 去重：dedup_key 默认绑定大级别 bar 时间戳，同一大级别 bar 内同规则同标的只报一次。

### FR-4 预警投递
- FR-4.1 多通道 Notifier 接口，失败重试与降级。
- FR-4.2 报警内容含：标的、规则、方向、触发价、各级别关键指标值、图表快照链接。
- FR-4.3 静默时段配置（例如加密夜间只报高优先级）。

### FR-5 Web 界面
- FR-5.1 (P0) 实时信号流 + 运行状态（连接、延迟、数据缺口）。
- FR-5.2 (P0) K 线回看，信号点标注，多周期联动。
- FR-5.3 (P1) 规则的增删改查 + 语法校验 + 立即历史回放试算。**已实现**（2026-08-31）；写端点默认关闭，见 CLAUDE.md「规则编辑与历史试算」。
- FR-5.4 (P2) 可视化规则编辑器。

### FR-6 回测与统计
- FR-6.1 回放引擎与实时引擎共用信号代码，仅 Feed 不同。
- FR-6.2 一致性校验：同一时段 replay 与 live 产出的信号必须逐条一致（数量、时间戳、价格）。
- FR-6.3 信号质量报告：按固定持有期与止损止盈两种口径统计。

### FR-7 交易（后期）
- FR-7.1 信号 → 意图(Intent) → 风控 → 执行网关，分层解耦。
- FR-7.2 风控：单笔上限、单品种上限、日亏损熔断、最大持仓、下单频率限制。
- FR-7.3 幂等下单与断线恢复（重启后与柜台对账，不重复下单）。
- FR-7.4 密钥加密存储，不入库明文、不进日志。

## 5. 非功能需求

- NFR-1 分钟级信号端到端延迟 < 3s（收盘到推送）。
- NFR-2 单进程支持 ≥ 100 标的 × 4 周期 × 20 规则，常驻内存 < 1.5GB。
- NFR-3 崩溃/重启后状态机可恢复，不丢单不重报。
- NFR-4 纯逻辑层（指标/形态/规则）100% 可脱离网络与磁盘单测。
- NFR-5 全部时间戳内部统一 UTC 存储，展示层按市场本地时区渲染。

## 7. 已知风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 未来函数 / 信号重绘 | 回测虚高，实盘失效 | as-of 视图强约束 + M2 live/replay 一致性校验 |
| 主力换月假信号 | 大量误报 | 预警按真实合约；连续合约仅回测用 |
| 期货夜盘跨日切 K 线 | 多周期错位 | 交易日历驱动的 BarBuilder，早期与行情软件对拍 |
| 数据商与 CTP 代码不一致 | 下错单 | SymbolRegistry 单一事实源 + 启动期校验 |
| 开发机 2核4G / 磁盘剩 7.6G | 跑不动全量回测 | 只存 bar 不存 tick；重回测放 VPS 或 Windows |
