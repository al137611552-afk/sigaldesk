# 买卖点标记 · 设计画布

三个方向画在**同一段行情、同一批标记点**上（含一处 3 信号密集簇），
避免"换个数据看着就好看了"的自欺。选定结果与口径见
[ADR-0012](../../adr/ADR-0012-marker-collapse-and-priority.md)。

| 文件 | 内容 |
|---|---|
| `gen.py` | 生成那 44 根确定性 K 线（三块画板共用，改一处三块同时变）|
| `build.py` | 由 `gen.py` 的几何数据产出三块画板 + `canvas.json` |
| `Main.dc.html` | 方案 A · 引线胶囊（每个点都带价格）|
| `DirectionB.dc.html` | 方案 B · 极简徽章（常态只有 B/S，点中才展开）|
| `DirectionC.dc.html` | 方案 C · 成对交易带（开仓与平仓连成一笔，中间挂盈亏）|

**选定：B+C**。常态用 B（不遮 K 线，九宫格里一格才 1/9 屏宽，A 的胶囊会立刻挤爆），
已成交的叠一层 C（复盘时每笔走了多远、赚还是亏一眼看完）。

## 重新生成

```bash
python3 build.py     # 重画三块画板
```

播种出的 `buy-sell-markers.html`（2.5 MB）是**产物，不进仓库** —— 它由本目录的
`.dc.html` 加设计工具的模板拼出来，改了画板重新播种即可。
