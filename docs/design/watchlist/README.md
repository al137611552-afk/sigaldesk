# 预警组 · 设计画布

多品种视图的设计稿。落地口径见
[ADR-0013](../../adr/ADR-0013-watchlist-group.md)，成品截图在 `../shots/panel-15-预警组.png`。

| 文件 | 内容 |
|---|---|
| `Main.dc.html` | 主视图。**可点**：市场 tab、周期、模式切换、每格的钉图标 |
| `CellStates.dc.html` | 单元格六种状态：常态 / 未读新触发 / 已钉住 / 无规则盯着 / 空槽 / 悬停 |
| `Flow.dc.html` | 三步闭环：预警组横扫 → 九周期竖看 → 单图找买点 |

复刻的是现有面板的 token（同一套颜色、`.cell-head` 的 4px 8px、格子 1px `--line`
分隔线、`.tab` 的 2px accent 下边框），所以画布上量到的间距可以直接抄进 `styles.css`。

## 重新生成

播种出的 `watchlist-group.html`（约 2.5 MB）是**产物，不进仓库** ——
它由本目录的 `.dc.html` 加设计工具的模板拼出来，改了画板重新播种即可。

**别直接用浏览器打开 `.dc.html` 看**：那样没有运行时，`{{hole}}` 会原样显示，
截出来是一屏占位符（踩过一次）。要看得开播种后的整页。
