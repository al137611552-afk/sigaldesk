# ADR-0003 形态层三档：表达式 / 结构原语 / Python 插件

- 日期: 2026-08-28
- 状态: Accepted

## 背景
需求覆盖三类形态：指标类、K线与价格结构类、以及无法预先枚举的自定义逻辑；
同时后期要做可视化规则编辑器（需要形态可被结构化描述）。

## 决策
统一注册表 + 三档表达能力：
- **A 表达式**：白名单 AST 求值（`ast.parse` 后按节点类型白名单校验，禁 `eval/exec/import/Attribute`）。
- **B 结构原语**：`breakout / range / swing_high / swing_low / gap / engulfing / pin_bar / consolidation`
  等注册为普通函数，与指标同表，可在表达式里自由混用。
- **C Python 插件**：`@pattern(name, params)` 装饰器注册，入参为受限的 `PatternCtx`。

## 权衡
- A/B 可被 UI 结构化编辑（未来可视化编辑器只需覆盖 A/B）；C 不可视化，但保留完整逃生舱。
- 不内建缠论/波浪：其递归结构（分型-笔-线段-中枢）工作量足以单独占一个里程碑，
  且实现分歧大。架构上通过 C 档插件位保留，需要时作为独立包接入。

## 已知限制
- C 档插件由用户自己写，可能有 bug；但因 `PatternCtx` 已物理截断未来数据，
  最坏情况是形态判断错，不会污染回测有效性。
