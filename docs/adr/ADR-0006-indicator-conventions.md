# ADR-0006 指标口径约定（EMA 播种 / MACD 柱 / 标准差除数 / Wilder）

- 日期: 2026-08-28
- 状态: Accepted

## 背景
"MA20 是多少"没有歧义，但 EMA、MACD、RSI、BOLL、KDJ 在国内外软件之间**口径确有分歧**，
同一根 bar 能算出不同的数。规则阈值（`rsi(14) < 45`）是照着某个软件的屏幕写出来的，
口径一旦和用户看的软件不一致，规则要么不触发要么乱触发，而且**极难排查**——
因为两边都"没错"，只是定义不同。

因此把口径一次性定死、写进代码注释与本 ADR，并用单测钉住。

## 决策

| 项 | 本项目取值 | 分歧对象 |
|---|---|---|
| **EMA 播种** | 前 n 个样本的 **SMA** 作种子，第 n 根出首值（TA-Lib 口径） | 部分国内软件用首个样本直接播种 |
| **Wilder 平滑** | `alpha = 1/n`，独立于 EMA 的 `2/(n+1)`；RSI 与 ATR 都用它 | 误用 EMA(n) 会让 RSI 明显偏离所有主流软件 |
| **MACD 柱** | `hist = 2 × (dif − dea)` | 西方软件多用 `dif − dea`，**差 2 倍** |
| **BOLL 标准差** | **总体**标准差（除以 n） | 部分实现用样本标准差（除以 n−1） |
| **KDJ** | `k=(2k+rsv)/3`、`d=(2d+k)/3`、`j=3k−2d`，k/d 均以 **50** 起步 | 起步值取 50 是国内通行做法 |
| **预热期** | 一律返回 `None`，**绝不用 0 顶替** | —— |

MACD 柱取国内口径，是因为本项目主战场是国内期货，规则阈值要能照着屏幕上的数字直接写。

## 权衡
- 优点：口径唯一、可复现，回测与实盘、两个市场之间都一致。
- 代价：与部分软件在**前若干根**有差异（EMA 播种方式不同），但差异按 `(1-alpha)^k`
  指数衰减，很快收敛；不影响长序列上的信号。
- 代价：接现成的 TA 库（TA-Lib/pandas-ta）会更省事，但它们各自的口径也不统一，
  且都不是增量结构（ARCHITECTURE §4.1 要求 O(1) 更新，回测与实盘同一条路径）。
  自建约 200 行，换来口径可控 + 增量可控，值得。

## 预热期为什么必须是 None
拿 0 当"还没算出来"的值，会让"均线尚未形成"在表达式里表现为"价格跌到 0"——
`close > ema(close,60)` 在预热期恒真，于是每条规则在数据刚接上的头 60 根里疯狂误报。
这是最典型的假信号来源，所以宁可让表达式求值在预热期直接判定为"不成立"。

## 数值稳定性
滚动窗口和用"加新值减旧值"是 O(1)，但浮点误差随更新次数**单调累积**，
跑几十万根后与全量重算就对不上。本项目每满一个窗口用 `math.fsum` 重算一次，
摊还仍是 O(1)，误差被钉在一个窗口之内（`indicators/base.py::Rolling`，有 20 万次更新的单测）。

## 验证
`tests/test_indicators.py` 里的 `*_ref` 是**故意写成朴素全量重算**的独立参照实现
（每个位置从头算一遍），与增量实现逐点对拍，相对容差 1e-9，
两个市场的真实行情夹具各跑一遍 —— 这是 M1 的第一条验收。
