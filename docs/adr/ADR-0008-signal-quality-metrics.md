# ADR-0008 信号质量统计口径

- 日期: 2026-08-31
- 状态: Accepted

## 背景
PRD 的第二个目标是"一条形态到底赚不赚钱，用历史数据跑一遍给出统计，而不是凭感觉"。
但"胜率 62%"这种数字极易在四个地方被做假，而且做假的人往往没有恶意 —— 默认值就是那样。
把口径一次性定死，并在报告里**原样带上口径**，否则数字没有意义。

## 决策

### 1. 入场价默认取信号**次根 bar 的开盘价**
信号在 bar 收盘时才成立，那个收盘价已经过去、成交不到。用它统计会**系统性偏乐观**，
对"放量突破"这类信号尤其严重 —— 信号那根本身就走了一大截。
`entry_on_next_open=False` 保留了旧口径，但它在报告里会被标出来。

### 2. 同一根 bar 同时触及止损与止盈时，**一律记止损**
bar 数据（OHLC）给不出高低点的先后。取止盈就是在给自己发奖；取止损是保守的下界。

### 3. 成本按**双边**扣，且默认为 0
`cost_bps` 是**单边**基点，一进一出扣两次。默认 0 意味着得到的是**毛收益**，
报告会把这个参数原样打出来 —— 一份没写成本的高频规则胜率没有参考价值。

### 4. `neutral` 方向的信号**不进胜率与收益**
它是"去看一眼"的提示，不是方向判断。把它算进胜率等于给自己注水。
但它仍计入触发次数与 MFE/MAE —— 那些对它是有意义的。

### 5. 同时给**固定持有期**与**止损止盈**两种口径（FR-6.3）
两者在一次评价里同时生效：先到先算，都没到就持有到期按收盘价结算。
退出原因（`stop`/`target`/`horizon`/`no_data`）逐条记录，
"假信号率"就定义为**先打止损的比例**。

### 6. 记录 MFE / MAE（最大有利/不利偏移）
只看最终收益看不出"止损是不是设太紧了"。平均浮盈远大于平均收益，说明利润没拿住；
平均浮亏接近止损距离，说明止损位置在噪声里。

### 7. 波动率自适应止损是**默认口径**（2026-09-04 由"可选"改为默认）
期货各品种波动率差异极大，固定百分比会让活跃品种全打止损、呆滞品种永不触发，
横向比较根本不成立。`atr_key` 指向信号快照里的 ATR 值，用 ATR 倍数替代百分比。

**默认值只有一个来源：`OutcomeParams` 的字段默认**（`atr_key="atr14"`,
`stop_atr=1.5`, `target_atr=3.0`）。面板两个接口、纸上撮合、两个 CLI
一律不再自己写字面量。

> **为什么要单独立这一条。** 原来 `atr_key` 默认是 `None`：`/api/stats` 与
> `/api/rules/trial` 都没传（=固定百分比 0.5%/1.0%），而 `trade/loader.py` 和
> `scripts/rule_eval.py` 传了 `atr14`（=ATR×1.5/×3.0）。同一条信号，面板显示的
> 止损位和模拟盘用的不是一个数，两边都不报错。
> `risk_distances()` 是**共用函数**——共用函数一点都挡不住，**分家的是参数**。
> 由 `tests/test_web.py::test_exit_convention_defaults_agree_across_call_sites` 钉住。

### 8. 每条结果记下自己用的是哪套口径（`Outcome.exit_basis`）
`atr_key` 设了、但某条信号的快照里没有那个值（规则的 `context:` 没声明 atr14，
或触发时还在预热期）会**静默回落**到百分比。回落本身是对的，
**看不出回落了**才是问题：一批信号里混着两套口径，报告上毫无异常，
横向比较却已经不成立。

所以每条 `Outcome` 带 `exit_basis`（`"atr"` / `"pct"`），报告里有
`by_basis` 分组，出现两个键时终端报告和面板都会显式告警。

## 权衡
- 优点：口径唯一、写进报告、纯函数可复现（M3 验收"两次统计结果完全一致"因此是结构性成立的）。
- 代价：默认口径偏保守，规则看起来会比用"信号收盘价入场 + 零成本"难看。这是有意的。
- 代价：按 bar 评价拿不到 bar 内的价格路径，止损滑点无从体现。
  真实滑点要等 M4 纸上撮合才有意义。

## 已知限制
- `no_data`（信号之后数据不够）单独标记，不当成 0 收益混进胜率 —— 否则最近的信号会稀释结论。
- 统计不做资金管理与复利：`total_return` 是等权累加，不是账户曲线。账户口径属于 M4。
